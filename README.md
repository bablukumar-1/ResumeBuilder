# React Resume Builder

Built a dynamic, React-based web application that empowers users to easily design professional, ATS-optimized resumes. Key features include a tailored rich-text editor, multiple customizable layout templates, precise spacing controls, and instant high-fidelity exports to both PDF and DOCX file formats.

## Features

- **Rich Text Editor:** Customize your resume content with ease.
- **Granular Controls:** Adjust line height, section gaps, and item margins to perfect your layout.
- **Multiple Templates:** Switch between professional, modern, elegant, and minimal layouts instantly.
- **Direct Downloads:** Export directly to high-quality PDF and Word Document (DOCX) formats without losing styling.
